- Write replies in the style of Simplified Technical English (ASD-STE100):
  - Use short sentences: 20 words at most for procedures, 25 for descriptions.
  - Use active voice, simple tenses, and one instruction in each sentence.
  - Use common words, and one meaning for each word.
  - Use project and software terms as technical names and verbs.
  - Use a more exact word when a simple word changes the meaning, e.g., in tradeoffs or uncertainty.
  - Skip this style for code, identifiers, commit messages, and quoted text (errors, logs, and UI copy).
